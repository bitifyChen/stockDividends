### Goodwinlab.ai 台股產業鏈地圖

- 網址：https://www.goodwinlab.ai/supply-chain
- 參考用途：台股產業鏈流向圖、上游 / 中游 / 下游結構、產業鏈分類 UI。
- 觀察重點：
  - 以產業鏈代碼分頁，例如 `半導體 D000`、`被動元件 J000`、`印刷電路板 L000`。
  - 單一產業鏈內再分上游、中游、下游。
  - 每個階段底下有細分類，例如 IC 設計、IC/晶圓製造、光罩、化學品。
  - 股票可掛在特定產業鏈與流向階段下。
- 後續研究方向：
  - 評估我們是否需要建立 `industry_chain`、`segment`、`flow_stage` 類資料結構。
  - 先不要直接爬取或複製該網站資料作為正式資料源，需確認授權或改用可授權資料來源。
  - 目前前端先使用既有 `industry_code` mapping；細產業鏈資料待後續正式設計。
